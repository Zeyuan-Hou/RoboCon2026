# 双环 ADRC 控制器参数测定方法

以下为 `DualLoop_ADRC` 控制器中各参数的测定方法，适用于位置和速度控制系统（如伺服电机、机器人关节等）。方法结合理论分析和实验步骤，确保参数的准确性和系统性能。

## 1. 位置环比例增益 `kp`
### 作用
`kp` 决定位置环的响应速度和稳态误差，影响速度指令的生成。

### 测定方法
- **理论指导**：`kp` 通常与系统带宽相关，初始值可根据期望的响应时间估算。快速响应需要较大的 `kp`，但过大可能导致振荡。
- **实验步骤**：
  1. 将速度环和 LESO 参数暂时禁用（`kv = 0`, `w0 = 0`），仅保留位置环。
  2. 施加一个阶跃位置指令（例如从 0° 到 10°）。
  3. 从小值（例如 `kp = 0.1`）开始，逐渐增大 `kp`，记录系统响应（位置随时间变化）。
  4. 选择满足以下条件的 `kp`：
     - 响应时间达到期望值（例如 90% 目标位置的到达时间）。
     - 无明显振荡或超调（超调 < 10%）。
  5. 使用示波器或日志记录位置误差，检查是否稳定。
- **注意**：若系统有较大惯量或阻尼，`kp` 需适当减小。

## 2. 最大允许速度 `v_max`
### 作用
`v_max` 限制速度指令，保护机械系统和执行器。

### 测定方法
- **理论指导**：`v_max` 基于执行器（如电机）的额定速度或机械系统的安全速度。
- **实验步骤**：
  1. 查询执行器规格（如电机数据手册），获取最大额定速度（单位：度/秒）。
  2. 考虑机械系统的物理约束（如齿轮减速比、负载限制），取较小值作为 `v_max`。
  3. 在实际系统中施加最大速度指令，验证是否引发过载或振动。
  4. 设置 `v_max` 为额定速度的 80%–90%，以留出安全余量。
- **示例**：若电机额定速度为 3000 RPM（18000 度/秒），减速比为 10:1，则 `v_max = 18000 / 10 * 0.9 = 1620` 度/秒。

## 3. 速度环比例增益 `kv`
### 作用
`kv` 控制速度环的误差响应，影响系统的动态性能。

### 测定方法
- **理论指导**：`kv` 与速度环带宽相关，通常比 `kp` 大以确保速度跟踪快于位置响应。
- **实验步骤**：
  1. 固定 `kp` 为已测定的值，禁用 LESO（`w0 = 0`）。
  2. 施加一个阶跃速度指令（例如 50% 的 `v_max`）。
  3. 从小值（例如 `kv = 0.1`）开始，逐渐增大 `kv`，记录速度响应。
  4. 选择 `kv` 使速度误差快速收敛（例如在 0.1 秒内达到稳态），且无明显振荡。
  5. 检查控制量 `u_total` 是否接近 `u_max`，若频繁饱和，则减小 `kv`。
- **注意**：`kv` 过大可能放大噪声，需与滤波器配合。

## 4. 加速度前馈增益 `ka`
### 作用
`ka` 通过前馈补偿提高速度响应的动态性。

### 测定方法
- **理论指导**：`ka` 与系统惯量和加速度响应相关，通常较小以避免过补偿。
- **实验步骤**：
  1. 启用位置环和速度环（`kp` 和 `kv` 已确定）。
  2. 施加快速变化的阶跃速度指令，记录加速度（通过速度差分估算：`(v_t - v_{t-1})/dt`）。
  3. 从 `ka = 0` 开始，逐渐增加，观察是否减少速度跟踪误差。
  4. 选择 `ka` 使加速度响应平滑，无明显超调或振荡。
  5. 若系统噪声较大，可减小 `ka` 或禁用（`ka = 0`）。
- **注意**：`ka` 需与 `dt` 匹配，确保前馈计算准确。

## 5. 观测器带宽 `w0`
### 作用
`w0` 决定 LESO 的扰动估计速度，影响抗扰性能。

### 测定方法
- **理论指导**：`w0` 通常设为速度环带宽的 3–10 倍，需平衡响应速度和噪声放大。
- **实验步骤**：
  1. 启用位置环和速度环，初始设置 `w0 = 10`（假设速度环带宽约 1–5 Hz）。
  2. 施加外部扰动（例如手动施加负载或改变目标位置）。
  3. 记录 LESO 状态 `z2`（观测速度）和 `z3`（观测扰动），检查是否快速跟踪实际速度和扰动。
  4. 逐渐增大 `w0`，直到 `z2` 和 `z3` 开始振荡或受噪声影响明显。
  5. 选择 `w0` 为振荡前最大值的 70%–80%。
- **注意**：若反馈信号噪声较大，需配合低通滤波器减小 `w0`。

## 6. 系统模型参数 `b0`
### 作用
`b0` 是系统增益的估计，用于 LESO 扰动补偿。

### 测定方法
- **理论指导**：`b0` 近似于控制量到速度的传递函数增益，形式为 `b0 ≈ 1/J`，其中 `J` 是系统等效惯量。
- **实验步骤**：
  1. 禁用 LESO（`w0 = 0`），施加已知控制量 `u`（例如 10% 的 `u_max`）。
  2. 测量系统的速度响应 `v`（度/秒），估算 `b0 = v / (u * dt)`。
  3. 重复多次实验，取平均值以提高准确性。
  4. 若系统模型复杂，可通过最小二乘法拟合 `u` 和 `v` 的关系。
  5. 验证 `b0`：启用 LESO，检查 `z3` 是否正确估计外部扰动。
- **注意**：`b0` 偏差较大可能导致补偿不足或过度，需反复验证。

## 7. 最大控制量 `u_max`
### 作用
`u_max` 限制控制输出，保护执行器（如电机）。

### 测定方法
- **理论指导**：`u_max` 基于执行器的最大输出能力（如最大电流、电压或扭矩）。
- **实验步骤**：
  1. 查询执行器规格，获取最大控制量（例如电机的最大 PWM 占空比或电流）。
  2. 在空载条件下施加最大控制量，验证系统是否安全运行。
  3. 设置 `u_max` 为额定值的 80%–90%，以确保安全。
- **示例**：若电机最大 PWM 为 1000，设置 `u_max = 900`。

## 8. 最小摩擦补偿系数 `fc_min` 和摩擦补偿增益 `fc_gain`
### 作用
`fc_min` 和 `fc_gain` 用于低速区的非线性摩擦补偿。

### 测定方法
- **理论指导**：`fc_min` 对应静态摩擦，`fc_gain` 调节动态摩擦补偿强度。
- **实验步骤**：
  1. 在低速运行（< `deadzone`）时，施加小控制量，记录刚好启动运动的 `u` 值，计算 `fc_min = u / u_max`。
  2. 施加不同速度指令（例如 10%、50% 的 `v_max`），记录摩擦力变化，估算 `fc_gain` 使补偿曲线匹配实际摩擦特性。
  3. 使用非线性函数（例如 `fc_min + fc_gain * (1 - vel_ratio)`）拟合实验数据。
  4. 验证补偿效果：检查低速区是否平滑运动，无抖动或突变。
- **注意**：需根据系统摩擦特性（如粘性摩擦、库仑摩擦）调整。

## 9. 速度死区 `deadzone`
### 作用
`deadzone` 确定触发摩擦补偿的低速范围。

### 测定方法
- **理论指导**：`deadzone` 基于系统机械间隙或传感器噪声水平。
- **实验步骤**：
  1. 在无控制量（`u = 0`）时，测量速度反馈的噪声幅度，设置 `deadzone` 为噪声的 1.5–2 倍。
  2. 施加低速指令，观察系统是否平稳启动，调整 `deadzone` 直到无抖动。
  3. 验证：确保 `deadzone` 不影响正常速度控制。
- **示例**：若速度噪声为 ±0.5 度/秒，设置 `deadzone = 1.0` 度/秒。

## 10. 控制周期 `dt`
### 作用
`dt` 是控制器的采样周期，影响所有动态计算。

### 测定方法
- **理论指导**：`dt` 由硬件定时器或控制循环频率决定，通常为 0.001–0.01 秒。
- **实验步骤**：
  1. 检查控制系统的采样频率（例如 100 Hz 对应 `dt = 0.01` 秒）。
  2. 确保 `dt` 足够小以捕捉系统动态（通常 < 系统时间常数的 1/10）。
  3. 验证：记录控制循环时间，确认 `dt` 恒定且准确。
- **注意**：若 `dt` 变化较大，需优化定时器或考虑自适应控制。

## 实验工具与建议
- **硬件**：示波器、数据采集系统、编码器或速度传感器。
- **软件**：MATLAB/Simulink（仿真和参数优化）、Python（数据分析）、实时日志工具。
- **步骤**：
  1. 从位置环开始，逐级调谐 `kp`、`kv`、`ka`。
  2. 启用 LESO，调谐 `w0` 和 `b0`。
  3. 最后调整摩擦补偿参数（`fc_min`、`fc_gain`、`deadzone`）。
  4. 在不同工况（空载、满载、扰动）下验证参数的鲁棒性。
- **记录**：保存每次实验的响应曲线（位置、速度、控制量），便于分析和优化。

## 注意事项
- **安全性**：在调参时，限制 `u_max` 和 `v_max`，避免损坏硬件。
- **噪声处理**：对反馈信号应用低通滤波，减少噪声对 LESO 的影响。
- **迭代优化**：根据实际系统响应，反复微调参数，确保性能与稳定性平衡。
