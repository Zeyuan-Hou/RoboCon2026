# 障碍赛自动路径二维可视化使用说明

这个工具用于在浏览器二维图里查看：

```text
蓝线：期望路径
绿线：实际走过的路径
红点/红箭头：机器人当前 xy 和 yaw
```

它是一个独立 Python 脚本，不需要加入 `colcon build`，不会修改导航控制逻辑。推荐使用网页版本：机器人端运行 HTTP 服务，你在本地浏览器查看，不依赖 RViz、matplotlib、numpy 或 SSH 图形转发。

## 1. 文件位置

```text
src/visual/obstacle_nav_web_plot.py
src/visual/obstacle_nav_xy_plot.py
src/visual/使用说明.md
```

## 2. 默认支持的流程

默认读取：

```text
src/config/quad_parku.yaml
```

当前主要支持障碍赛自动路径：

```yaml
navigation_mode: "RECORD_PARKU_REPLAY"
record_parku_replay_path: ".../replay_path.csv"
```

`replay_path.csv` 需要包含：

```text
s,x,y,yaw
```

脚本也简单兼容：

```text
POINT_SEQUENCE       -> 读取 target_points
TRAJECTORY_SEQUENCE  -> 读取 trajectory_files
```

## 3. 启动前准备

先启动障碍赛自动流程或至少启动会发布当前位置的话题。

默认实时位置话题是：

```text
/quad/lidar_pose_xyyaw
```

消息类型：

```text
geometry_msgs/msg/Point
x = x
y = y
z = yaw
```

可先检查：

```bash
source /home/cat/hitcrt_quad_ws/install/setup.bash
ros2 topic echo /quad/lidar_pose_xyyaw --once
```

该话题来自 `lidar_nav_demo_node` 中的 `lidar_pose_pub_`，注释为 `/quad/lidar_pose_xyyaw`。

## 4. 推荐：网页可视化

### 4.1 SSH 端口转发

在你的本地电脑终端连接机器人：

```bash
ssh -L 8765:localhost:8765 cat@机器人IP
```

保持这个 SSH 窗口打开。

### 4.2 机器人端启动网页服务

在 SSH 里运行：

```bash
cd /home/cat/hitcrt_quad_ws
source install/setup.bash
python3 src/visual/obstacle_nav_web_plot.py
```

然后在你本地电脑浏览器打开：

```text
http://localhost:8765
```

默认会读取 `src/config/quad_parku.yaml`，并订阅：

```text
/quad/lidar_pose_xyyaw
```

### 4.3 常用参数

指定配置文件：

```bash
python3 src/visual/obstacle_nav_web_plot.py \
  --config /home/cat/hitcrt_quad_ws/src/config/quad_parku.yaml
```

直接指定 replay 路径：

```bash
python3 src/visual/obstacle_nav_web_plot.py \
  --replay-path /home/cat/hitcrt_quad_ws/src/pythontool/record_parku/sessions/test08/replay_path.csv
```

如果不想用 SSH 端口转发，也可以让服务监听所有网卡：

```bash
python3 src/visual/obstacle_nav_web_plot.py --host 0.0.0.0 --port 8765
```

然后浏览器访问：

```text
http://机器人IP:8765
```

现场更推荐 SSH 端口转发，因为不需要开放机器人端口。

## 6. 使用其他实时位置话题

默认已经使用 `/quad/lidar_pose_xyyaw`。如果你要改用 `Float32MultiArray` 类型的话题，例如某些调试节点发布的 `[x, y, yaw]`：

```bash
python3 src/visual/obstacle_nav_web_plot.py \
  --pose-topic /quad/obstacle_nav/current_pose \
  --pose-type float_array
```

`float_array` 类型要求：

```text
std_msgs/msg/Float32MultiArray
data = [x, y, yaw]
```

## 7. 参数说明

```text
--config              指定 YAML 配置文件
--replay-path         直接指定期望路径 CSV，覆盖配置文件
--pose-topic          指定实时位置话题
--pose-type           float_array 或 point
--max-actual-points   最多保留多少个实际轨迹点，默认 20000
--host                web 服务监听地址，默认 127.0.0.1
--port                web 服务端口，默认 8765
--max-send-points     每次发给浏览器的最大点数，默认 6000
```

查看帮助：

```bash
python3 src/visual/obstacle_nav_web_plot.py --help
```

## 8. 常见问题

### 8.1 浏览器只有蓝线

说明期望路径读取成功，但没有收到实时位置。检查：

```bash
ros2 topic list | grep lidar_pose
ros2 topic echo /quad/lidar_pose_xyyaw --once
```

如果你实际发布的是 `Float32MultiArray [x, y, yaw]`，请使用：

```bash
python3 src/visual/obstacle_nav_web_plot.py \
  --pose-topic /quad/obstacle_nav/current_pose \
  --pose-type float_array
```

### 8.2 浏览器打不开 localhost:8765

检查 SSH 是否带了端口转发：

```bash
ssh -L 8765:localhost:8765 cat@机器人IP
```

检查机器人端脚本是否还在运行：

```bash
python3 src/visual/obstacle_nav_web_plot.py
```

### 8.3 提示找不到 replay_path.csv

检查 `src/config/quad_parku.yaml` 中：

```yaml
record_parku_replay_path: "..."
```

是否指向真实存在的文件。也可以用 `--replay-path` 临时覆盖。

### 8.4 坐标方向看起来反了

这个图只画原始 `x/y`。如果方向不符合现场直觉，优先检查：

```text
TF: camera_init -> aft_mapped
record_parku_replay_path 是否来自同一坐标系
/quad/lidar_pose_xyyaw 是否和回放路径坐标一致
```
